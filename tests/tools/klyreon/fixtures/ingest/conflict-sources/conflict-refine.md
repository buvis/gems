# Source: certainty holds only within a fixed frame of assumptions

<!-- stub-marker: conflict-refine -->

Converging evidence makes a claim certain, but only relative to a fixed frame
of background assumptions. Change the frame and the certainty lapses. This
narrows the unqualified claim rather than denying it.
