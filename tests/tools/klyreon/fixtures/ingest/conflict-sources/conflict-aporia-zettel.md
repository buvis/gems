# Source: the certainty question is a standing impasse

<!-- stub-marker: conflict-aporia-zettel -->

Whether evidence can confer certainty is a question that has resisted
resolution for centuries. The strongest cases on each side are equally matched.
This is best recorded as a standing aporia rather than decided.
