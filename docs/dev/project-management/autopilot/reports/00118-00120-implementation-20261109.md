## Deviations from the PRD text (all deliberate)

- 00119: the PRR heading is `# <title>`, not `# PRR: <title>`. bim's
  `align_h1_to_title` fixer keeps the H1 equal to the title, so the prefix
  would not survive `bim format` either.
- 00119: hook warnings reach `--json` as an additive `warnings` key; without
  it a missing `path_projects` root was invisible to scripts.
- 00119: hooks run after the path reservation and before the save, so a hook
  failure fails the create (`hook failed: ...`) with nothing written, instead
  of 00118's "note saved, but hook failed" wording.
- 00120: `daily_log`, `linked_contacts` and `archive` are additive JSON keys;
  `path_daily` and `path_articles` are keyword-only constructor arguments that
  default to None (feature off) so the TUI and serve call sites and existing
  tests keep working. The CLI always passes them from settings.
- The argument-count lint (PLR0913/PLR0917) is ignored per file for
  `serve/_app.py` and `tui/create_note.py` in pyproject, the same precedent as
  `runlog.py`.
